# Quadros & Sabrina Quadros Advocacia — Landing page

Site estático (HTML + CSS + JS, sem build). Publicado na Vercel a partir da branch `main`.

## Estrutura
- `index.html` — página
- `css/styles.css` — estilos base · `css/tema-moderno.css` — camada visual moderna
- `js/main.js` — animações e links de WhatsApp (número em `WHATSAPP_NUMBER`, no topo)
- `images/` — fotos · `fonts/` — Garet e Gentlemens Script
